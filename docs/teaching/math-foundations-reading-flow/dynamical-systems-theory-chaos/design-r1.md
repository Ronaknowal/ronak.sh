## Learning contract and continuous route

Keep the title, URL, eleven anchors and all sound old depth. A learner should be able to choose the state and clock, explain the geometric operation of a flow or update, analyze disturbances and basin changes, recognize an attracting cycle, construct the tent-map chaos mechanism, and judge what numerical evidence actually establishes. The current version already contains strong derivations and eleven complete programmes. Its weakness is that framed multi-mode labs and long reference passages often arrive before their visual objects have been taught.

The revision starts with two carts at the same position and opposite velocities. It then carries one question forward: what information and rule determine the next state, and what happens when either is disturbed? A scalar flow introduces signs and basins; a plane adds rotation and coordinate transfer; a return section turns an oscillation into a map; repeated maps introduce cycles and sensitivity; inverse branches explain folding; full Lorenz states and numerical structure show where a picture can mislead. Optimization and recurrence reuse these exact operations.

Use the shared lesson introduction, normal prose and subheadings, visible task prompts, shared independently open hints/solutions, readiness, connections/next, Further Learning, and a distinct Technical References ending. Put complete file links at the relevant code and a compact final file index. No lab H3 that repeats the section, no framed explanation atlas, no predict-before-reading gate, no hidden core diagram. Figure precedes its mechanism explanation after a short orienting lead; its controls follow the explanation of every exposed quantity. These are drawings of states, curves, tangent vectors, intervals and transformations, not sentence boxes with arrows.

Prerequisites are vector coordinates/matrix multiplication, derivative/chain-rule meaning and basic probability. Link their exact existing owners; supply short local refreshers because systematic Calculus and ODE occur later in module order. Existing Eigenvalues §4 already teaches map/flow stability and transient exceptions. ODE §§6–7 owns matrix-exponential/Jordan details and §§10–11 owns RK4/adaptivity/events; it is an optional later expansion, not an assumed earlier implementation. The current ODE scalar scratch step cannot be imported as a vector solver without a taught adaptation. Numerical Methods owns general error analysis. Next is actual route `it-calculus-stochastic-differential-equations`, whose stochastic increment/chain-rule contract has been inspected.

## Semantic colour and drawing rules

Use the existing neutral charcoal background. Select final colours against the real theme and test contrast, starting from amber `#efb95f`, blue `#76b9ed`, violet `#bb9be8`, coral `#ec8f82`, neutral light `#e4e1db` and muted guide `#9aa1ab`. No green/olive decoration. Colour has a local legend and stable identity: q/input/reference state amber; p/second coordinate/comparison state blue; radial/derived/tangent quantity violet; destabilizing correction or Euler error coral. For a method comparison, exact is neutral dashed, forward Euler coral with square points, symplectic blue with circular points. State-coordinate colours do not silently become stability labels inside the same view.

Attracting/repelling/one-sided equilibria use filled/open/half-filled symbols and labels, not red/green judgment. Start is a ring, selected state a filled dot, equilibrium a distinct cross or named marker so a single open dot cannot mean both initial state and instability. Curves carry line style and direct labels. Shared identities persist across panels; no more than four simultaneous families in one figure. Annotations sit beside the actual mathematical object. Meaningful area/length encodings use the true scale; small cylinders get a separately marked zoom with parent scale/bounds, never silently inflated width.

Use original responsive vector/DOM drawings, not generated raster art. Text inherits the reader font and actual enlarged size, including SVG labels; sparse ticks and exterior HTML labels are preferable to shrinking text. Default 320–375px width should stack linked panels while retaining objects and reading order. No compulsory horizontal scroll for the main mechanism. Optional detailed code/table overflow is local. Equal q,p coordinate scales remain equal after reflow; curves can be recomputed to the available plot box. Every figure has a useful text alternative stating the operation/outcome and an accessible selected-state summary. Animations, if any, are explicit play/pause with deterministic stopped default and reduced-motion handling. A time cursor alone is sufficient.
