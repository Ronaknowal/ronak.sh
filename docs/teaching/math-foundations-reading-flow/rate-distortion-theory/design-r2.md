## Purpose, route and conservation

A compressor lets several originals share one reconstruction. The learner should trace what the encoder sends, choose what errors cost, distinguish one finite code from an asymptotic limit, calculate binary/Gaussian limits, implement a finite optimizer and diagnose its certificate, then measure the bytes and paired error of an actual decoded stream. The current nine section titles/anchors stay stable. Its derivations and programmes contain useful depth; the revision changes their approach, diagrams, operation-level explanations and missing library/application bridges.

First pass: §§1–3 for code, budget and binary limit; §4's operational distinction and converse interpretation; §5's update trace and complete computational routes; §6's Gaussian allocation; §§7–8's criterion/actual-byte decisions; changed practice. The visible deeper branches hold the full converse, random-covering argument, auxiliary/KKT/certificate proof, covariance extension and learned-compression bridge. Nothing instructional folds. Only hints/solutions and retrieval feedback may collapse. The shared Learning compass links all nine actual main sections and names exact prerequisites; do not add a second contents list.

Preserve seven original full programme/output pairs, both checkpoints, all ten old tasks, exact support conventions, bit/nat conversion, stochastic test-channel versus deterministic finite-code distinction, tiny-positive-budget handling, float certificate qualification, all cost/criterion caveats and full toy byte protocol. Conserve title, route, reader progress and guide mapping. A new default initial picture must not expose untaught information-bound/entropy fields merely because the old lab computed them.

Starting story: eight equally likely three-bit source words, codebook ordered000/111, index0/1 and decoded source-length-three word. Show011 selecting111 by one mismatch versus two. Later change source prevalence explicitly; source rows then have probabilities p^k(1−p)^(3−k). Colours encode bit identity throughout this binary story, while codeword-group outlines distinguish the codebook destinations. Other sources are introduced as new experiments with their own named identities.
