# Mathematical and statistical drawing conventions

Scope: the 57 `math-foundations` topics, authorized 6 October 2026. Preserve stable IDs, section order, progress and earlier scientific evidence.

- Page surfaces use neutral charcoal and amber. Amber (`#edc267`) identifies the selected object/result; pale neutral (`#ded5bf`) identifies fixed reference objects. Muted cyan (`#97bfca`) marks a second operand/comparison, with a dashed line as well as colour. Do not introduce green/olive decoration. A probability fill encodes area only when its area is mathematically meaningful.
- Put short labels on the object or beside its endpoint. State values and axis meanings in reflowing HTML when geometry cannot carry them legibly. Never rely on colour alone. Solid arrows track the first operand; dashed arrows track a comparison; dotted connectors indicate a residual or an auxiliary construction. Specify any topic-specific change explicitly.
- For geometry use equal physical x/y scales, declared coordinate units and a visible origin. Comparable panels share domains; an input change must not silently erase a magnitude change through automatic rescaling. A drawn angle, area or length is a mathematical claim.
- Matrices are cell grids with row/column meanings, not boxes containing paragraphs. Tensors show their actual indexed slices or slabs and one tracked source value. Source and destination cells share an outline and labels. Edges and branches are actual connecting lines.
- Probability diagrams distinguish outcomes, event membership, mass/density, observations, parameter uncertainty and decisions. Draw conditional branches with their conditioning event and branch probabilities. Distinguish a density height from shaded probability area.
- First identify the entities/question in prose, show the drawing, then trace its parts, introduce the equation and connect the code. A lab is an inline responsive drawing with a small control row below; no banners, framed panels or separate lab headings. Existing shared reader opening, code and practice affordances remain.
- New terms and controls appear only after their meaning is available in reading order. Reuse names, units, symbols and fixtures across linked prose, drawing, formula, code and practice; explain deliberate changes.
- At desktop, 390 px and 768 px with 200% root text, inspect the actual painted marks and labels. Recompose into successive panels rather than shrink annotations. Provide a text equivalent and exact values for each drawing. Numerical/source checks and visual inspection are separate evidence.
