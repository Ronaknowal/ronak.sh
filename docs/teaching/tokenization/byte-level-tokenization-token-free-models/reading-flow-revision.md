Four runnable scratch/library programs remain unchanged. The defects are presentation and missing structural pictures throughout: framed labs put controls before their result; several figures are paragraphs in boxes; embeddings, masks and five distinct model structures must be imagined. Some pictures follow the prose that already explains them. Retain the title, stable ID, all section numbers, scientific qualifications, full programs, practice and ordinary-tool bridges.

The learner should trace a visible symbol into stored bytes, regroup without losing them, repair an incomplete stream, build causal training rows, locate where each architecture spends work, derive an entropy boundary/mean, and compare resources and likelihood in declared units. Exact byte representation does not promise model understanding, valid generated UTF-8, normalization reversibility, equal multilingual service or universal speed.
