## Assessment and intended outcome

The complete existing thirteen-section lesson supplies useful UTF-8 validity, normalization, ranked BPE, stateful decoding, causal targets/masks/loss, five architecture mechanisms, entropy, pooling, resource accounting and six solved transfer tasks. Four runnable scratch/library programs remain unchanged. The defects are presentation and missing structural pictures throughout: framed labs put controls before their result; several figures are paragraphs in boxes; embeddings, masks and five distinct model structures must be imagined. Some pictures follow the prose that already explains them. Retain the title, stable ID, all section numbers, scientific qualifications, full programs, practice and ordinary-tool bridges.

The learner should trace a visible symbol into stored bytes, regroup without losing them, repair an incomplete stream, build causal training rows, locate where each architecture spends work, derive an entropy boundary/mean, and compare resources and likelihood in declared units. Exact byte representation does not promise model understanding, valid generated UTF-8, normalization reversibility, equal multilingual service or universal speed.

### Primary claim locators and currency

- https://docs.python.org/3/howto/unicode.html — definitions/encodings, comparing strings, chunked I/O; canonical text/byte ladder.
- https://www.rfc-editor.org/rfc/rfc3629 — §§3–4 allowed masks/scalars and prohibited sequences; independent standard for code fixtures.
- https://www.unicode.org/reports/tr15/ and https://www.unicode.org/reports/tr29/ — forms, canonical vs compatibility, extended grapheme boundaries and versioning.
- https://huggingface.co/learn/llm-course/en/chapter6/5 — base symbols, weighted corpus pairs and merge-order walkthrough; previous lesson owns ranked engine.
- https://github.com/openai/gpt-2/blob/master/src/encoder.py and https://github.com/huggingface/tokenizers/blob/main/tokenizers/src/pre_tokenizers/byte_level.rs — byte bijection, prefix-space/regex flags.
- https://arxiv.org/pdf/2105.13626 and https://huggingface.co/docs/transformers/model_doc/byt5 — raw-byte encoder–decoder, encoder-heavy allocation; only ordinary byte IDs match our BOS protocol.
- https://arxiv.org/pdf/2103.06874 — CANINE hash bucket embeddings, local/down/deep/up anatomy; character, not byte inputs.
- https://arxiv.org/html/2106.12672 — GBST candidate blocks, scores/mixing/downsampling; no fixed-vocabulary assumption.
- https://arxiv.org/html/2401.13660v1 — MambaByte selective state-space path and speculative decoding; linear sequence work conditional on fixed state dimensions.
- https://aclanthology.org/2025.acl-long.453/ and https://arxiv.org/html/2412.09871v1 — BLT canonical architecture/patching; max-pool query initialization and cross-attention differ from our mean-pooling bridge. Author source https://github.com/facebookresearch/blt and API https://huggingface.co/docs/transformers/model_doc/blt are current ordinary implementation pointers. The complete paper implementation is not locally run.
- https://arxiv.org/html/2605.08044v1 — §§2–3 and 5, new decoder strategies, masked block parallelism and draft verification. Inspected as current research; no quantitative speed claims copied. Add ≤200-word qualified extension so existing scalar/causal/patch/core sequence remains coherent.
