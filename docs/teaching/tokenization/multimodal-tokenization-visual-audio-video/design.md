## Outcomes and checked prerequisites

The previous three lessons teach pieces/IDs, byte coverage, dictionary lookup and embedding-table costs. Link their exact stable routes. Reconnect an embedding to a vector locally; assume only basic arrays, arithmetic and Python. Explain nearest-neighbour distance, reconstruction, derivatives/gradient routing and positional information locally. A transformer-block derivation, CLIP contrastive training, perceptual-loss training, entropy coding, sampling and deployment are downstream owners, not silent prerequisites.

Learners should trace pixels to patch vectors, compare continuous and discrete interfaces, implement patching and quantization, explain and check the three VQ gradient routes, encode/decode residual codes, calculate separately bits and sequence positions, preserve time/spatial/codebook metadata, and diagnose lost evidence or a mismatched preprocessor. Reconstructed perceptual quality is not guaranteed by vector error or token count.

## Drawings, labs and colour contract

Draw all figures inline on page background; no card/title chrome. Controls immediately below actual drawings. Labels ≥12px at phone; recompose panels vertically rather than shrink whole wide SVG. Every SVG has title/text alternative. Nearby prose interprets the same example. Identity labels remain authoritative; no hue-only cue.

Global modality meaning: amber text, blue image, violet audio, rose video. Namespaces retain these colours. Patch/code identity uses an explicitly introduced local four-hue palette (amber/blue/violet/rose), labelled A–D or k0–k3; selection is a white/dashed outline. Pixel fill is a labelled grayscale0..1 scale, while patch borders carry identity. Encoder z is a labelled white circle, selected code a coloured square; residual is a dashed white arrow. Gradient routes use labelled directions and line styles; don't overload modality hues to mean train/frozen.
