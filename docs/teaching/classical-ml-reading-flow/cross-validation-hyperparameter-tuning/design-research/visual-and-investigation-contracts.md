# Object-level visual and investigation contracts

Design specification, not rendered assets or runtime evidence. IDs follow distinct conceptual jobs in the reading flow; their number is a result of this map, not a quota. Existing useful views may be adapted. A library of generic cards cannot substitute for the specified row arrays, fitted states, scores, uncertainty distributions or paid training histories.

## Common semantic and layout protocol

Follow the module's `visual-vocabulary.md`: use blue plus **T/train** labels for permitted fitting rows, rose plus **V/validation** labels for selection evidence, and violet plus **A/assessment** labels for protected outer rows. Amber indicates the inspected row/operation through an additional outline, preserving role colour. No green/olive decoration. Missing/unobserved is a hatched empty cell labeled absent; observed loss is a solid mark with its numeric value. Row identity is textual and stable across every connected view; color denotes role at the current stage, not permanent row identity. Candidate identity uses named k/scaler cards plus line/point shapes; selection uses an extra outline/focus ring, never a color swap that loses identity. Learned state has its own **fit on IDs…** header. Every arrow has a visible head and names its carried quantity; forbid arrows from protected labels back into fit/choice. Layout-only distance is not sample distance. Graphs label axes, units, generator and assumptions; empirical marks say retained observation, illustrative beliefs say constructed.

Within each section use a connecting question and one-line lead, then the view, its labelled-part walkthrough and worked operation, then equations and code. Do not put the picture after paragraphs that already depend on it. Every matrix has row/column names, dimensions and a HTML exact-value table or readable semantic equivalent. Narrow screens stack stages vertically with direction heads and preserved row IDs; wide sample matrices may scroll inside a labeled region with row labels visible. Never shrink all labels into illegible fit-to-width SVG. Separate captions from marks, leave arrow channels clear, use equal scales for compared quantities and inspect390/768/desktop after runtime authorization. Phone composition is specified now; paint/keyboard/overflow checks are deferred. Mathematical text reflows separately from geometry. Floating-point values retain enough digits to distinguish the actual claimed relation and identify rounded/approximate labels. Do not add clipping caps or implied ranking from rounded ties.

Checks below distinguish **retained** previously recorded numerical evidence, **new design arithmetic** in design-arithmetic.json and **future** writing/runtime verification. No design table count establishes completeness. Accessible text must explain the operation and worked result, not just “CV diagram.” Copy/Download applies later to every actual code block, preserving canonical filename/source and separate answer-role assets.

## Investigation protocol

All investigations show current inputs, mechanism/intermediate state, current output and causal explanation immediately. Valid edits update continuously; no answer commitment/reveal/grading controls. Select a row or edit actual values/assignments, not merely canned scenarios. Numeric inputs and keyboard equivalents supplement direct manipulation. Reset restores exact initial state and clears derived focus; stepping selects operation state with outputs already visible. Invalid inputs show a concrete refusal and no stale result labeled current. Seeded sampling exposes seed and sampled cards. No animated layout implies a speed claim. Retained fixtures below use their existing evidence; new fixture arithmetic is explicitly limited to source-free/design checks until meaningful new programme verification. The [simple local control ownership](design-fixtures.md#simple-local-control-ownership) contracts split distinct questions into adjacent small views, each with one to three changing quantities. These are fourteen ownership groups, not fourteen parameter dashboards or a fixed final lab count.
