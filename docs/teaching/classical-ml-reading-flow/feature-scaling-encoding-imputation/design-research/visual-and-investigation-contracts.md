# Actual-object drawings and playable investigations

Complete proposed design contracts, not implemented figures or native evidence. Read with `reading-flow-design.md`. D01–D41 identify distinct teaching jobs, not a minimum quota or proof of adequate diagrams. Closely connected panels may share one implementation only if their intermediate correspondences remain visible. L1–L14 identify families; L11a/L11b and L14a/L14b are separate focused investigations, giving sixteen investigations. No full manuscript or runtime construction is authorized at this gate.

## Common drawing protocol

Place each drawing immediately after its one-sentence lead and before the walkthrough that names its parts. Draw actual cells, coordinate axes, vectors, intervals, basis functions, sparse entries, coefficients and completed datasets. Prose in connected boxes is not a substitute for those objects. A boundary outline is legitimate only when it encloses the actual rows/state it separates. Labels live where their referents occur; formulas and long explanations reflow in HTML. A text/table equivalent supplies exact operands, units, ordering and state for every quantitative drawing.

Data roles: E = exact constructed example with a retained future calculation; H = retained historical ecological/numerical result with the original input/version/date; A = analytic function with stated parameters, not measurement. Every final caption identifies its role. No invented timing/performance or new fitted ecology. Current colour/selection/missingness conventions are in the main design. Missing estimates retain the original absence marker after filling. Do not render missing as an observed zero, an outlier as a clipped in-range point, or an unknown category as a biological fact.

At narrow widths, stack logically separate panels with repeated axes/column headers; do not shrink a complete desktop SVG to unreadable labels. Use equal physical axis scale for distance/circle geometry, common declared scales for comparable panels, full-domain plus zoom for outliers, and visible labelled continuation for a deliberately cropped coordinate view. Full quantitative values remain accessible. Pan/zoom may alter the viewport, never computed values. In labs, edit domains and axes stay synchronized; no hidden clamp. Stable axes during pointer changes; expand on committed changes with an explained domain if necessary. Exact values do not snap to unrelated grids. Native keyboard/pointer, intermediate width, 390/320px, 768px at200% text, label/arrow/point collisions and changed-state completeness all require later inspection.

## Focused playable contracts

Controls appear directly below the picture they change. Each opens with the complete current output, linked intermediate values and interpretation. Reset always restores values, draft editors, selection/inspection and text together; repeated valid edits work without commit/reveal. An invalid finite/domain input keeps its visible draft plus a local error, and either labels the last valid output with its actual configuration or clears affected results; it never silently displays old output as current. Blank means missing only where the local contract says so. No learner prediction, answer-choice commitment, correctness/verdict, check-to-reveal or optional ungraded bypass. Reset and a meaningful algorithm-step control are navigation, not answer gates.

## Coverage and review obligations

Bins, polynomial products and B-spline recursion receive full static worked drawings and complete changed-input programmes. A second many-control basis dashboard is unnecessary; learner-controlled basis parameters live in those actual programmes and transfer tasks. This is a deliberate representation choice, not missing computational coverage. Nonlinear lambda fitting, group/time encoding and proper-MI generation receive separate visible traces/code even where a browser refit would add little learning value.

Each final drawing needs an author reading of its complete adjacent section and actual geometry, numeric/semantic guards for its values and mappings, then personal native inspection at representative desktop/narrow/increased-text states. All informative lab states, not just defaults or DOM counts, require real control operation. Different whole-runtime/native review follows author review. Historical scripts that still test prediction gates cannot certify these successors. Model checks, build success, screenshot acquisition or count checks cannot replace diagram assessment. Explicitly retain any unavailable native surface or access limit; do not claim a fresh visual pass from source hashes.
