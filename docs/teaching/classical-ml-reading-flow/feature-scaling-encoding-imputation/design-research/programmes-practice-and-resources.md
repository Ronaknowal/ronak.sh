### Mathematical contracts for the new fitted mechanisms

P7's bounded maximum-likelihood fit uses transformed population variance v(λ). For positive Box–Cox inputs, its objective up to a constant is ℓ(λ)=−n log(v(λ))/2+(λ−1)Σlog(x). Yeo–Johnson replaces the last sum with Σsign(x)log(1+|x|). Show the transformed-variance and Jacobian contributions separately. Zero variance is a degenerate objective, not an accepted normalizing fit. A boundary maximum is reported as such; the bounded search is not labelled a global guarantee. Standardization, when requested, is a separate saved affine map after the power transform.

P8's worked five landmarks are values[1,2,2,4,100] and reference probabilities[0,.25,.5,.75,1]. The declared bidirectional interpolation averages the two possible values at a duplicate: x2→.375, x3→.625; below/above the fitted extent map to0/1. Normal output uses the explicitly chosen finite epsilon1e−7 before inverse CDF. For a constant fitted column c, the custom map uses0 belowc, .5 atc and1 abovec; that is a declared convention and must be compared with the actual library behavior instead of claimed identical. This also makes the information loss and inverse limitations visible.

P10's kmeans bins use a complete local one-dimensional Lloyd routine: supplied finite ordered initial centres, nearest-centre assignment with a declared tie rule, per-cluster means, explicit empty-cluster retention and cap/status, then midpoint edges of sorted distinct final centres. Keep this supported toy algorithm distinct from ordinary library initialization/default convergence details. Quantile bins choose linear percentiles explicitly, remove duplicate interior edges, and use right insertion for membership at an interior edge. Outside fitted endpoints goes to the first/last bin; effective bin count is returned. No uninspected earlier implementation is needed.

P11's first recurrence fixture uses degree1 and full extended knots[−1,0,1,2,3], corresponding to base knots[0,1,2]. At x=.5, the three basis values are[.5,.5,0]; at x2 they are[0,0,1] under the supported boundary convention. Draw these actual intersections and row entries before a higher-degree example. The manuscript derives the recurrence, including zero-width terms and supported boundary/extrapolation rules, rather than merely presenting scipy's result.

P16 uses explicit prior parameters μ₀,κ₀,α₀,β₀, with κ₀,α₀,β₀>0. Given n observed scalar values with mean xbar, κₙ=κ₀+n, μₙ=(κ₀μ₀+n·xbar)/κₙ, αₙ=α₀+n/2, and βₙ=β₀+Σ(x−xbar)²/2+κ₀n(xbar−μ₀)²/(2κₙ). Draw σ² from inverse-gamma(αₙ,scale=βₙ), μ conditionally from Normal(μₙ,σ²/κₙ), then missing values conditionally from Normal(μ,σ²). Ordinary SciPy's joint distribution receives(μₙ,κₙ,αₙ,βₙ). This is a marginal normal model with an explicit ignorability/MCAR teaching assumption, not a conditional MAR model with unimplemented covariates. A no-observation case is labelled prior-only, and the lesson's complete-data mean/variance analysis requires at least two total values. A proper prior alone is not a claim that every frequentist pooled interval has valid coverage.

### Implementation efficiency and completeness

NumPy reductions, stable sorting/interpolation, sparse constructors, BLAS/least-squares, scalar optimization and random distribution generators are explicit primitives. The lesson owns fitted statistics/schema, policy/masks, donor eligibility, forward/inverse transforms/objectives, feature construction, fold donor sets, conditional iteration and pooling. These core methods must not be replaced with calls to the same ordinary estimator being compared. Explain time/workspace costs beside the actual loops. Avoid repeated distances per missing target and dense vocabulary projection matrices; avoid rewriting a low-level numerical optimizer for pedagogical theatre. Float overflow or unsupported domains produce honest refusal/diagnostics rather than false coordinates.
