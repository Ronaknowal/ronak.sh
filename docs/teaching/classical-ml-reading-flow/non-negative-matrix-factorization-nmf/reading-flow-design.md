## Continuous entities and conventions

Start with three measured bins F0/F1/F2 and two constructed patterns C0=[1,0,1], C1=[0,1,1], each in arbitrary intensity units per unit amount. Row R0 combines amount[2,1], giving[2,1,3]. F0/F1/F2 identities are labelled throughout. C0 is blue, C1 rose; later component IDs use the module nominal vocabulary plus direct IDs/patterns. Amber denotes current attention, white outline selection; neutral is observed/result/reference, signed residuals use a separately labelled diverging scale. No green/olive decoration, no colour-only distinction.

Extend to R1 amounts[1,3]→[1,3,4] and R2 amounts[0,2]→[0,2,2]. Thus H0 is2×3, W_exact is3×2 and X0 is3×3. Mathematical indices i=1…n,c=1…k,j=1…d explicitly bridge code zero-based IDs. W carries row-specific amounts; H contains one pattern per component row; (WH)[i,j]=sum_c W[i,c]H[c,j]. These constructed patterns are explanatory, not learned physical spectra. Shape drawings precede dot/outer products and objective sums.

For fitting, introduce W_start as all ones while holding H0 fixed: reconstructed row[1,1,2]. R0 coordinate update makes[2,1] exactly; R1 cyclic sweep makes[2,2.5], not the final row optimum[1,3]. The sweep is deliberately distinct from solving all coordinates simultaneously. The shared unpenalized objective is L=½||X−WH||²_F; ordinary library reconstruction_err_ is not this half-square automatically. Predictions may exceed1; exact saved digit maxima remain visible, never clipped.

Switches are explicit: two-feature cone slices remove F2 only for geometry; signed SVD/PCA examples permit negative directions to contrast constraints; positive scalar observations for IS avoid zero support; real digits introduce8×8 bins and saved component count8; constructed text replaces feature units with count/TF-IDF weights; spectral example uses three bands and optional sum-to-one; online changes row arrival while retaining component/feature orientation; tensors add an axis instead of silently flattening it. Every switch restates entities/units/fitted-versus-editable roles.
