## General input, arithmetic and state contract

All local dense routes support moderate-size float64 arrays with finite nonnegative real values. Refuse boolean, complex, object, negative or nonfinite data, mismatched shapes or feature order, invalid integer rank/caps and out-of-domain loss/penalty/mask parameters. Fit needs positive n and d; an empty query returns the correct `(0, fitted_k)` shape without fitting. Zero observed rows are legitimate. Input finiteness does not promise finite products: validate Gram/cross products, supported ratios, reconstructed blocks, objective and diagnostic reductions. Overflow/underflow outside the stated support is a clear refusal suggesting rescaling, never a hidden epsilon or clipped fake result.

Construct each candidate in local temporaries. Publish factors, immutable ordered feature IDs, fitted rank, objective/diagnostics and any A/B accumulators together only after all validation and supported arithmetic succeed. Rejected fit/partial_fit leaves the complete earlier snapshot usable. Query operations derive shapes from that snapshot, not mutable next-fit configuration. Ordinary-library wrappers fit a fresh candidate estimator before publishing it; do not claim the library itself guarantees failed-refit atomicity. Returned arrays are copies or read-only snapshots. A promised main includes default, changed, empty, malformed and rejected-state witnesses during content preparation; design arithmetic alone is not an implementation test.

## Complete mechanism ownership and ordinary routes

**N1 — arrays, objectives and diagnostics.** Teach `nonnegative_table`, explicit factor/mask/parameter validators, safe reconstruction blocks, half-Frobenius/KL/beta branches, projected-gradient terms and snapshot publication. Named dimensions prevent accidental broadcasting. Half-square objective is `0.5*sum((X-WH)**2)`; MSE divides twice this by observed cell count, while a norm is its square root. Use block rows for diagnostics to avoid a full nd residual; input nd and returned encodings nk still exist. Keep zero-pattern flat coordinates distinct from missing observation quality. For a nonnegative coordinate, projected gradient is g when w>0, min(g,0) when w=0. Ordinary route is explicit NumPy operations and objective recomputation against sklearn results, not an unexplained delegated optimizer.

**N2 — efficient cyclic constrained coordinates.** `coordinate_block(X,W,H,...)` forms G=HH.T and P=XH.T once per fixed-H block. It updates a component column across rows via `max(0,w_c-((WG-P)_c+l1+l2*w_c)/(G_cc+l2))`, using fresh earlier coordinates; equivalently isolate the other coordinates and divide `(P_c-sum_other w_tG_tc-l1)` by `(G_cc+l2)`. The l2 slope and curvature must both appear. N2's core unpenalized route sets l1=l2=0, and N7 introduces these penalties after their scalar derivation. H uses the transposed row-oriented problem and new W. Unpenalized fit alternates W first, then H; fixed-H `transform` changes only new amounts. `CoordinateNMF.fit_transform`, `transform`, `inverse_transform` and diagnostics have complete coherent fitted state. Zero G diagonal with zero data cross product is flat in the unpenalized route: choose coordinate0; the penalized branch includes its stated slope/curvature and support. An inconsistent nonzero cross product or nonfinite cache is refused. Initial factors, ordering, cap and nonnegative stopping tolerance are explicit. Stop uses a declared projected-gradient baseline; zero baseline is already stationary, cap termination is reported as cap, and neither certifies global truth.

An outer cache construction costs O(ndk+(n+d)k²); q inner cyclic sweeps add O(q(n+d)k²), with O(ndk) reconstruction diagnostics separately. Input/returned factors require O(nd+nk+kd). Transient caches require O(k²+max(nk,kd)) in a sequential implementation, plus row-block O(bd+bk) diagnostics and optional O(t) history. Fitted query state needs H(k,d), feature metadata and diagnostics; retaining train W is optional and stated. This is an efficient dense reference, not an optimality/timing claim. Public `NMF(n_components=k, init='custom', solver='cd', beta_loss='frobenius', shuffle=False, alpha_W=0, alpha_H=0, ...)` receives named initial W/H and diagnostics. Ordinary final factors need not equal scratch factors; compare shapes, objective and stationarity under declared tolerances. D20's one-sweep arrays and D36's fixed-block comparison explain order before any full fit.

**N3 — constrained encoding/reference.** Scratch fixed-H encoding reuses N2, not unconstrained solve-and-clip. `scipy.optimize.nnls(H.T, x, maxiter=...)` is the ordinary convex route per row; H.T is d×k and the returned norm is not half-square loss. Compare predictions/objective/KKT when coefficients are nonunique. Teach the exact clipped failure `[0,1]` against H_c, dependent/zero patterns and query refusal. Alternating NNLS performs n row calls and d feature calls against the other factor. Its active-set iterations/workspace depend on the solver/problem, so do not promise a whole-sweep O(ndk) bound or universally faster fit. Do not import an undocumented private sklearn NNLS helper.

**N4 — complete multiplicative fitting.** Own Frobenius and generalized-KL H-first then new-H W updates, including factor copies, named numerator/denominator shapes, loss and stationarity diagnostics, caps and support. Frobenius caches permit O(ndk+(n+d)k²) per dense outer update. KL prediction/ratio products cost O(ndk), with nd prediction/ratio workspace unless a block accumulation is explicitly implemented. If both numerator and denominator are zero on an unused supported coordinate, retain that coordinate as a flat-update convention; inconsistent positive-over-zero ratios refuse. Exact factor zeros stay zero: supported descent does not certify KKT. KL observed0/prediction0 contributes0, observed0/prediction>0 contributes prediction; positive observed/prediction0 is infinite and refused. No epsilon floor changes the objective silently. Ordinary `NMF(solver='mu', beta_loss='frobenius'/'kullback-leibler', init='custom', ...)` is a distinct configured implementation, not promised one-step equality. D25 recomputes only one original supplied block, preserving all40 original sweeps/stdout.

**N5 — general beta-MM.** Complete row-oriented loss and MM power gamma(beta)=1/(2-beta) below1, one on[1,2], and1/(beta-1) above2. Stable dedicated beta2/1/0 branches precede generic powers. The local general-beta implementation supports strictly positive data, factors and reconstruction; finite intermediate arithmetic is required. Wider zero domains at Frobenius/KL exist mathematically and in N4, not silently in this narrower route. Each dense ratio/update is O(ndk) with nd prediction/ratio workspace. D30 holds ratio4 fixed to isolate the exponent; it is not a full fit. Public NMF MU/beta configuration and documented input-zero restriction for beta<=0 are explained. No transplanted all-beta Frobenius proof, scale-free count interpretation or audio experiment.

**N6 — full uncentred initialization.** Use NumPy `linalg.svd(X, full_matrices=False)` on uncentred X; m=min(n,d), U(n,m), s(m), Vh(m,d). First rank-one triplet uses oriented/absolute leading vectors; subsequent positive/negative sign parts compare paired norm products, normalize only nonzero parts, scale by `sqrt(sigma*selected_product)`, deterministic positive-pair ties. A zero singular term yields zero factors without division. k<=min(n,d) is required by this NNDSVD route; a separate positive-random route supports overcomplete models.
