## One continuous learning path

Each local sequence is question → short lead → actual drawing → named-part
walk-through → equation → explained code. `lesson-flow` scopes the shared inline
reader. No card frames, banners, preset walls, prediction/reveal gates or hidden
teaching. Only independent practice hints and solutions are disclosures. Draw the
actual objects and wires before relying on behavior plots. Full programs stay
visible with shared Copy feedback and Download; the final index names all dependencies.

Structure colours follow the DL vocabulary: supplied input cyan, learned weights
amber, computed state/probabilities violet, operations white, solid forward arrows
grey. Matrix values separately use positive amber, negative blue, zero neutral,
with actual numbers and named axes; thick white marks the traced row. History curves
are six distinct directly named series/dashes. No hue alone identifies a quantity. Connected selective/SwiGLU cutaway circles round to two decimal places while adjoining ledgers retain more digits and calculations use full precision. Learned embedding/classifier biases stay amber. Actual current SiLU operands change with the input; never hard-code the default operand in a live label.

Diagram text is native16px, and SVG physical size uses width/16 rem. At200% root
text, labels become32px; do not squash the same giant diagram into tiny phone text.
Large drawings/tables use focusable named local scrollers with visible pan guidance,
keyboard arrows and independent edge-label checks. Controls are directly below their
own current visual and have at least44px target height. Captions may wrap naturally.
