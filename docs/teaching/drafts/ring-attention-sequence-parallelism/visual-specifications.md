## Loading, failure and exact state

Small constructed calculations are bounded and pure; raw large dataset, fits and results are not fetched by the runtime. The model packet has one cached promise, rejected requests evict it, and stale responses/unmounted effects are guarded. Input points and local selectors exist before needed near-viewport loading and survive failure/retry; current inference is memoized from actual dependencies. Every failure action uses shared amber FlowControls. Frozen-model source changes recompute only the selected case, with no fits or user-supplied dynamic source URLs.

Scalar pins contain actual scores/values/permissions/blocks/order/offset/output. Record pins contain all arrays/G/metadata/owners/output/dQ/dK/dV. Model pins contain all45points, source/model-execution/head/query settings and15probabilities. Separate reset counters clear rejected numeric/owner drafts even if the last valid value did not change. Last valid results are labelled when drafts are invalid; invalid collective dimensions display no prior result as current. Editing source and changing ownership are never conflated.
