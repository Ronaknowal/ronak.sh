# Saved observations

These JSON results and event journals are exact copies of the four successful
once-run stages. They are sufficient to inspect finite-store traces, scalar
comparisons, model inputs, all comparison summaries and native backing addresses.
The .pt names/hash/size fields in journals identify locally retained raw tensor
operands; those binary files are intentionally not included in this lightweight
download. They are not missing files required to run the examples. A fresh run
creates its own tensors. No weights, credentials or model cache are bundled.

The original source-manifest.json continues to bind the unmodified study inputs.
files.json is a separate delivery index for this expanded downloadable bundle.
