# Supplied Iris measurements

The offline file is the corrected `sklearn.datasets.load_iris()` copy exported with named columns and local row IDs. It has 150 rows, four finite feature values per row and a separate species annotation. Features are sepal length, sepal width, petal length and petal width, all in centimetres. Local IDs 0–149 preserve this file's order; they are neither timestamps nor globally assigned specimen IDs.

Attribution: Fisher, R. (1936), *Iris* [Dataset], UCI Machine Learning Repository, [DOI 10.24432/C56C76](https://doi.org/10.24432/C56C76). [UCI's dataset entry](https://archive.ics.uci.edu/dataset/53/iris) identifies the [CC BY4.0 license](https://creativecommons.org/licenses/by/4.0/). This adaptation adds named CSV columns and local IDs, and encodes species as 0=setosa,1=versicolor,2=virginica. No creator endorsement is implied. Species is excluded from clustering features and is used only for separately declared retrospective assessment.

The immediate distribution came from scikit-learn 1.9.1. Its corrected rows include ID34=[4.9,3.1,1.5,.2] and ID37=[4.9,3.6,1.4,.1]; replacing the file with another historical Iris distribution may change exact comparisons. The whole current CSV is 3418 bytes with CRLF records, SHA256 `13c9255444bce09fd9df60cccfec34d5b0a0eeebc06008fb4e2b836aa2caf78a`. Equivalent LF records are 3267 bytes, SHA256 `387c9585511b1d4ab2513075377d2f07c5cbf05e7a04fd934fcb254290a7a651`. This is a line-ending distinction, not changed feature values.

The seven saved fit reports describe this finite selected collection. Their scaler used all 150 descriptive rows; they do not estimate held-out future performance. Numerical fitted scaler arrays are not retained in these fit records. The record reader validates the supplied values/order and reports saved labels/roles/scores without fitting a model. The complete ordinary fitting source is also supplied separately. Constructed trails, unit-conversion rows and rings are different examples and are not additional Iris observations.
