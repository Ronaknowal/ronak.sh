# Offline Iris data provenance

This packet carries `iris.csv`, 150 observed rows plus a header, for the real-data GMM example. It is not a synthetic dataset and is not fetched when the learner runs the program.

* **Dataset:** Fisher, R. (1936), *Iris*. UCI Machine Learning Repository, [DOI 10.24432/C56C76](https://doi.org/10.24432/C56C76), [dataset page](https://archive.ics.uci.edu/dataset/53/iris). The UCI record was reviewed12 September2026 and identifies four real-valued measurement features, 150 plants, three species with50 rows each, no missing values and centimeter units. UCI donation date is30June1988. The historical analysis concerns distinguishing species from measurements; the lesson reuses measurements for unsupervised density estimation.
* **License:** the UCI dataset record explicitly supplies [Creative Commons Attribution4.0 International](https://creativecommons.org/licenses/by/4.0/). Attribution is retained here and in the manuscript. The additional observation IDs and CSV column names are author transformations. No implication of endorsement by Fisher, UCI or scikit-learn is intended.
* **Exact input snapshot:** exported12September2026 from `sklearn.datasets.load_iris()` in scikit-learn1.9.1, NumPy2.3.5, Python3.12.14. The installed bundled dataset makes this export offline. This is the corrected scikit-learn snapshot, not a byte-for-byte copy of UCI's historical `iris.data` text file. UCI flags historical differences in the35th and38th samples; the supplied rows35 and38 are respectively `4.9,3.1,1.5,0.2,setosa` and `4.9,3.6,1.4,0.1,setosa`. Record this distinction when comparing a different Iris download.
* **Rows and columns:** `observation_id` is one-based source order1–150 and is never a feature. Measurements are `sepal_length_cm`, `sepal_width_cm`, `petal_length_cm`, `petal_width_cm`, preserved to the source's one-decimal reporting precision. `species` uses the supplied names `setosa`, `versicolor`, `virginica`, each appearing50 times. The complete150×4 measurements are retained; fitting uses only the two sepal columns.
* **Preprocessing and split:** `np.random.default_rng(16).permutation(150)` creates one label-blind ordering. First90 IDs train, next30 validate, last30 test. All exact one-based IDs and the training-only StandardScaler means and population-standard-deviation scales are supplied in `gmm_saved_iris.json` under `iris`; the original workspace `checked-results.json` is historical evidence, not a required downloadable sibling. Species enters only the final test ARI; it affects neither split, scaling, candidate fitting nor model selection. The candidate grid is K1–4 and all four covariance types, with five starts each and the explicit settings in the manuscript.
* **Sampling limitation:** this is a selected balanced-species collection. Mixture weights and density describe this representation and collection procedure. They do not estimate natural species prevalence, a modern geographic plant population or a time-independent operating baseline. Duplicate/rounded measurement combinations are retained because they are part of the data and help explain the narrow-variance diagnostic.
* **Current physical integrity:** the supplied UTF-8 `iris.csv` is 4528 bytes with 151 CRLF line endings (150 rows plus header), physical SHA256 `32041679ae8a4827b7f43d867bf3733966116f77d65e88d28209416995888f0e`. The common file index records this actual identity. Decoding newline pairs to LF gives the historical 4377-byte CSV payload with SHA256 `c6fd24e7f41dd55405cbc30f344e648c2f31eedfb24f9dcaba6290998bc26eb7`, the role described by the old `iris.csv_sha256` scientific recorder. These are the same row values but different byte serializations; do not compare the physical hash to a decoded hash as though they were identical. The protected historical provenance/writer/results remain unchanged.

A separate LF export from the same installed snapshot can call `load_iris()`, write these columns in source order, add IDs beginning at 1, format measurements to one decimal place, use `iris.target_names[target]`, and explicitly choose writer line terminator `\n`. That describes the historical decoded payload; it is not a claim that the current physical download uses LF.

For a fresh numerical reproduction, download the complete supplied `iris_density.py` and this `iris.csv`, place them in one directory, install the versions in `setup-guide.md`, and run `python iris_density.py` FROM that directory. Its public ordinary estimator recipe fits the declared sixteen candidates; fresh results are separate from the saved outcomes printed in the lesson. For inspecting retained results without a new fit, download `saved_iris_mixture.py`, `gaussian_mixture.py`, `gaussian_log_density.py` and `gmm_saved_iris.json`, then run `python saved_iris_mixture.py --report` from their directory. The full-precision split/transform/candidate/results record is the supplied JSON, and the complete recorded streams are in the common index.

Historical `author-calculations.py` and `checked-results.json` are workspace scientific evidence, not downloadable dependencies or a runnable command available in this standalone packet. Their exact protected snapshots remain retained, and existing workspace copies are not modified or executed here. Use the supplied routes above; do not assume an absent standalone author runner or regenerate a historical evidence receipt. The Bayesian weight continuation additionally requires the complete `iris_density.py` namespace as explained in setup.
