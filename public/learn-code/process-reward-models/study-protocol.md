# Prospective local PRM study

Frozen 7 October 2026, after different design acceptance and before extraction or fitting. The accepted design is SHA256 `671ee0800d49d21c6732b6004620f8929c18c78cb3a7f2f80480b24a61f0ce49`. This small experiment answers whether a transparent lexical classifier can learn these retained three-category labels. It does not compare PRM and ORM on a benchmark or reproduce a paper's model.

Inputs are the complete newline-terminated records retained from two bounded upstream HTTP ranges at PRM800K commit `7ecc794703b2877f63226f2477a49b34f9b25163`. Train: 2,093,513 bytes, SHA256 `08f6e0728ac42b417293613d033f92092f806b369e6398a7e1a0abc12435ec07`; test: 2,096,959 bytes, SHA256 `143b6e1e495f1b6ec836099f264ff5b6e35e8bc7070b2b1474f9ed992ddd1244`. The actual MIT notice is retained. Full upstream LFS objects were not downloaded or verified. These convenience prefixes have biased coverage.

Exclude quality-control and initial-screen records and finishes other than `solution` or `found_error`. At each annotated step, all alternatives share the earlier *chosen* path. Keep a current alternative only when its rating is −1, 0 or +1, it is unflagged and all earlier chosen steps have known unflagged ratings 0 or +1. A missing/flagged/negative earlier chosen step stops subsequent known-valid-prefix extraction. A documented human continuation may extend that path only when its own rating is known, unflagged and nonnegative. The retained raw data contain no such human continuation; the implementation nevertheless handles its documented object schema explicitly. Never infer the next prefix from an unchosen sibling or generated future step. Preserve unknown/negative/flagged rejection counters and exact record/step/alternative source addresses.

Use exact UTF-8 problem SHA256 to group. Sort eligible upstream-train identities; select first 96 train and next 32 validation. Select first 48 eligible upstream-test identities. Smaller pools use actual available groups without duplication. Deduplicate exact `(problem, chosen-prefix list, current text, rating)` tuples before keeping the first 12 eligible examples per problem in source order. Splits must be disjoint by problem; IDs never enter features. Freeze the selected records and extraction source before fitting. This prefix cap favours early steps and is part of the study's limitation.

Map upstream −1/0/+1 to classes invalid/neutral/progress 0/1/2. Lexemes are word runs, numeric runs or individual non-whitespace symbols. Hash each exact lexeme with SHA256, first eight bytes interpreted big-endian modulo 512 for its bucket; byte 8's low bit supplies sign (+1 for zero, −1 for one). Prefix and current-step halves have separate 512 buckets. Divide each half's signed counts by the square root of its lexeme count; an empty half is all zero. Prefix text is question followed by earlier chosen steps, separated by newline. Order is lost within each half and collisions remain; no answer, target, verifier score or identity enters a feature.

NumPy `default_rng(23)` initializes a 1024×3 Gaussian weight matrix with standard deviation .01, plus three zero biases. Perform exactly 160 full-batch SGD updates, learning rate .1, objective mean three-class cross-entropy + (.001/2) times squared weight norm; biases have no regularization. Retain updates 0, 20, 40, 80, 160 for all splits: mean CE, three-class Brier (sum over classes then mean examples), accuracy, confusion matrix and class counts. Use final update 160; no data-dependent checkpoint or hyperparameter selection. Baseline class probabilities are training counts with Laplace-1 smoothing.

Record all selected-case predictions, initialization, final weights, feature contract, environment, sources, counters and outcomes. Display a correct and a wrong held-out prediction by first stable source address if each exists, otherwise state their absence. Retain weak/negative outcomes; acceptance never depends on improvement. Ordinary Torch checks matched logits/gradients/updates with these data and initialization without a second scientific fit. A random small Transformers classifier tests sequence/API contracts, not pretrained mathematical competence. Constructed rollout/search/policy examples are separate from this corpus study.

No fit or model selection occurred before this protocol was saved. Subsequent execution receipts bind exact protocol, extraction source, selected data, fit source and outputs. Changes require an additive declared continuation, not silent replacement of the retained experiment.
