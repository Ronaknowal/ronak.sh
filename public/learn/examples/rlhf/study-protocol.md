## Constructed complete token loop

The token experiment has a separately declared constructed criterion and data. Vocabulary `[PAD, BOS, EOS, one, sentence, France, Italy, Paris, Rome, is, capital, of, .]` has 13 IDs in that order. Prompts are BOS + instruction (`one` or `sentence`) + country. Short responses are capital + EOS; long responses are capital + `is capital of` + country + `.` + EOS. The four prompt combinations supply eight demonstrations, both lengths once for each prompt, deliberately giving the initial policy imperfect instruction matching. Four comparisons prefer the appropriate length for each instruction and correct capital; four more prefer correct over swapped capital at the appropriate length. Every label is constructed and named as such.

Use the actual earlier TinyLM backbone: width32, two heads, two layers, context16, dropout0. Actor's new scalar value head reads each pre-action final hidden state. Seed31; CPU float32, two Torch threads. Response-only SFT: all eight sequences per batch, 120 AdamW updates, learning rate .003, weight decay0, global norm clip1, token-mean cross entropy including EOS, prompt/PAD targets excluded. Reward model: a separate same-sized backbone plus scalar head at the final valid token; seed37, all eight comparison pairs, 120 AdamW updates, learning rate .002, weight decay .01, gradient norm clip1, mean pair softplus. Record its pair accuracy and scores, including novel generated responses; freeze it after fitting. Center its outputs by the mean training-response score, computed once from both candidates; no variance scaling.

Reference is a deep frozen copy of SFT actor. Actor/value shared backbone continues from SFT, value head starts with the seed31 initialization; reference has no trainable role. Temperature1 full-vocabulary sampling, no top-k/top-p or rejection sampling. All 13 IDs remain in the actual distribution, so malformed PAD/BOS draws are visible generated tokens, not silently discarded; PAD validity is determined from stored lengths, not token equality. EOS stops a response. Maximum8 generated actions is a declared finite-horizon terminal, not a continuing-task timeout. Value bootstrap0 at either end. Recompute prefixes without KV cache.

Twenty PPO collection rounds, 16 responses each, four prompts repeated four times, sampling seed101+round. Keep old log probabilities/values detached for all inner updates. Each action's shaped reward is `-.1*(old_logp-reference_logp)` and the centered learned reward is added at the final action. Gamma1, lambda.95, GAE; valid-only population normalization with epsilon1e-8. Use four epochs per rollout, minibatches of four whole trajectories with fixed seeded permutations. Policy surrogate and squared value error each use the **mean over valid tokens in that minibatch**; this weights tokens rather than whole response sums. Minimize negative clipped surrogate plus **.5 times mean squared value error**, no additional .5 hidden in the MSE definition, no entropy bonus, no value clipping. Clip epsilon .2, AdamW .001, weight decay0, global norm clip1. Log the token denominator so variable-length weighting is visible. Old-policy arrays, frozen reward and reference must remain unchanged; actor and critic must change on nonzero examples.

Evaluate SFT and after rounds5/10/15/20 on the same four prompts, eight independent generated responses per prompt with seed901 fixed per checkpoint. Report learned proxy score, explicitly supplied exact-response task criterion (correct capital and instructed length), sampled sequence log-ratio sum, response length/EOS/malformed counts, current actor-value error on the latest rollout and literal token outputs. Held-out generalization is not claimed: these four constructed prompts are reused deliberately to expose the mechanism and proxy gaps.
