Changes: Strip each selected source row's outer whitespace and retain its first
256 characters. Select the first80 eligible train prose rows and first20 each
validation/test prose rows, in source order. No Unicode normalization,
punctuation repair or generated replacement text. Retained records include the
source row and article title. The corpus and response provenance are embedded
in wikitext_excerpt.json. The official rows API does not identify its served git
revision; the recorded dataset repository revision is retrieval context, not
a claim of byte equality with a pinned Parquet release.

Code and original constructed examples in this directory are separate from
the WikiText excerpt; this notice covers the corpus text.
