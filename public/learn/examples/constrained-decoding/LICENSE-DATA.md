The archive is retained unchanged. This lesson adapts rows 0–3, 50–53 and
100–103 to a two-field structured extraction exercise, rather than the original
species classification benchmark. Prompts, JSON schema and evaluation are new
educational transformations. The dataset documentation records historical
source corrections; the frozen archive hash identifies the exact version used.
