# Structured decoding examples

Python 3.12+. Create a virtual environment and install requirements.txt. The
recorded environment used CPU Torch 2.14.0+cpu on Windows; use the official Torch
CPU wheel index if your default install selects another build. Model generation
explicitly disables Torch compilation and uses two CPU threads. Native package
wheel availability depends on platform; no GPU or hosted API is required.

## Start with the finite mechanisms

    python automata.py
    python token_index.py
    python finite_schema.py
    python nested_parser.py
    python constrained_loop.py
    python conditioning.py
    python costs.py
    python practice.py

automata/finite_schema/nested_parser/conditioning/costs use the Python standard
library; constrained_loop additionally needs NumPy. token_index imports the
adjacent automata module. Keep the files together. sampling.py is the exact
positive-support sampler from the preceding Decoding Strategies lesson.

The regex compiler takes an explicit AST, not arbitrary regex source. The
schema compiler deliberately handles only required finite string/number enums
in a closed object with one canonical serialization order. The recursive
parser accepts nonempty nested arrays and single digits, with a depth limit.
The loop's score provider is a deterministic example, not a neural network.
raw_bytes_hex preserves generated bytes even if a cap or cancellation leaves
an incomplete UTF-8 character; text is null and utf8_status names that state.

## Inspect saved real outputs without another generation

    python evaluate.py --data data.json --records study --output my-evaluation.json

study/evaluation-exact.json contains the current exact-number analysis;
study/evaluation.json retains the original float-validator analysis. Use a new output
name: writes are exclusive so a new run cannot silently replace evidence.
All 48 actual Pythia outputs, source prompts, protocol, setup and model identity
are included. Exact Decimal validation accepts 5/12 manual-XGrammar and 12/12
Outlines schema outputs; the original float parser accepted 12/12 in both.
Seven manual outputs spell 5.0999999999999996, outside the exact-tenths enum
even though binary float parsing rounds them to 5.1. Every arm has zero exact
two-field extractions. Derived replay flags explicitly name the manual
XGrammar schema recognizer; they are not each backend's internal completion. Single serial CPU times
are descriptive observations, not serving benchmarks.

    python native_matchers.py --output my-native-masks.json

This bounded native XGrammar example uses no language model. It inspects masks,
padding, EOS, reset, fork and atomic rollback. native-masks.json retains the
observed output. An earlier version used an unavailable __version__ attribute
after its assertions; the corrected example reads package metadata. That
metadata failure did not affect the separate frozen pretrained study.

## Recreate data or perform a new, explicitly separate model run

    python prepare_data.py --zip iris.zip --output my-data.json

The fixed UCI archive hash, 150 records and chosen row indices are checked.
Each prompt uses the same schema; no per-row gold value enters its grammar.

Acquire the pinned model files into pythia-14m (network access required):

    python -c "from huggingface_hub import snapshot_download; snapshot_download(repo_id='EleutherAI/pythia-14m', revision='cf967c0a9a04383db6f7b1108d86b2962634b4ac', local_dir='pythia-14m', allow_patterns=['config.json','generation_config.json','model.safetensors','tokenizer.json','tokenizer_config.json','special_tokens_map.json'])"

Weights are not in this bundle. The following offline commands use that exact
directory; the generator checks the recorded weights hash before loading.

    python generate_native.py --stage prepare --model pythia-14m --data data.json --output my-study
    python generate_native.py --stage run --model pythia-14m --data data.json --output my-study

Prepare freezes exact current model/data/program/version identities. Run uses
greedy decoding, 48-token cap and four declared arms on twelve rows. Existing
completed records are reused only if bound to that protocol; a started row
without a result stops silent replay. A copied historical study belongs to
its original environment and is for inspection, not continuation after changing
packages. Use a new output directory for a new study. Outlines returns text;
strict parsing, schema validation and source-field comparison follow separately.
